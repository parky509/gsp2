== Description ==

A comprehensive investment dashboard plugin for WordPress with:
* User wallet balances
* Multiple transaction types (deposits, withdrawals, transfers, conversions)
* Admin approval workflows
* Email notifications
* Glass morphism design

== Installation ==

1. Upload the plugin files to `/wp-content/plugins/gsp2-investment-dashboard/`
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Configure settings at GSP2 Dashboard → Settings
4. Add `[gsp2_dashboard]` shortcode to any page
